# 📰 News Research Tool

A Streamlit-based application that allows users to input news article URLs and ask questions based on the content of those articles using OpenAI's language models and vector embeddings.

---

## 🚀 Features

- Load and parse content from any two news article URLs.
- Automatically chunk, embed, and store document vectors using FAISS.
- Query the embedded knowledge using natural language.
- Retrieve accurate answers along with sources using Retrieval-Augmented Generation (RAG).

---

## 🛠️ Requirements

- Python 3.8+
- OpenAI API key

### 📦 Python Libraries Used

- `streamlit`
- `langchain`
- `langchain-openai`
- `faiss-cpu`
